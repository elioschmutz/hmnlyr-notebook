Wissenssammlung zu Technologien, Frameworks und Programmiersprachen: Snippets, Howtos und Skripte.

## Aufbau

```
Code/
└── <Technologie>/          z. B. WordPress
    ├── <Technologie>.md    Übersicht
    └── <Thema>/            z. B. Plugins, WP-CLI, Child Themes
        └── <Notiz>.md      Snippet, Howto oder Skript-Doku
```

- Pro Technologie ein Ordner mit einer Übersichtsnotiz gleichen Namens.
- Darin pro Thema ein Ordner. Ob Snippet, Anleitung oder fertiges Skript, ist egal: Alles zum selben Thema liegt beisammen.
- Gehören zu einer Notiz weitere Dateien (z. B. ein Skript), bekommt sie einen eigenen Unterordner.
- Jede Notiz trägt die Tags `#code` und die Technologie (z. B. `#wordpress`). Neue Notizen legst du mit der Vorlage [[Code-Eintrag]] an.
